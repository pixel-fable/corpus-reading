# corpus-reading

> 一大批材料交给 AI 读，怎么算「读过了」，怎么算「没读」。

一个面向 AI 编程助手（Claude Code / DSH）的技能包：把「读完一堆语料」从一种态度，变成**带分母、带区间、可被第三方验算的估计量**。

---

## 这个是什么

这是给 AI 助手用的**技能文件**，不是可执行程序。

把 `SKILL.md` 放进助手的 skills 目录，助手在遇到「把这堆材料读完」「提炼结论」「这堆里有没有 X」这类任务时会自动加载它。

---

## 解决什么问题

把几万行对话、几百个文件丢给 AI，最常听到的两句话是：

- 「我读完了」（实际读了 7%）
- 「这里没什么有价值的内容」（实际是他没抽到）

这个技能把这两句话堵死，换成可验证的口径。

---

## 最关键的几条（完整版见 `SKILL.md`）

**1. 先选方法，再谈抽样**

```
能检索      → 别抽样
能精读      → 别委派
能量（脚本）→ 别读
```

抽样是**兜底**，不是首选。只在「连关键词都构造不出来」时才用。

**2. 覆盖率只认三种口径**

| 口径 | 报法 |
|---|---|
| 逐条读 | 行号区间 `1—4,120 行` |
| 全量清点 | 条数 / 文件数 |
| 抽样 | 方法 + **种子** + 区间 |

**分母必须写在分子旁边**——不是「读了 1,423 行」，是「19,581 行里的 1,423 行」。

**3. 抽样要给置信区间，宽度超 25% 就不许下结论**

```
p̂ = m/n
CI = p̂ ± 1.96·√(p̂(1−p̂)/n)
n  = z²(1−p)/(ε²p)     达到 ±ε 需要的样本量
```

**4. 用数据证伪自己**

> 任何「这块没价值」的判断，必须先抽一次样，给它一个被推翻的机会。

技能里附了三次真实判反的记录，其中一次是「最有价值的部分」实测只有 0.2%。

**5. 抽样不能替代精读**

抽样只回答「哪里有东西」，不回答「那东西是什么意思」。依赖顺序的材料（法律条文、代码）禁止跳读。

## 内容

```
.
├── SKILL.md      # 技能主文件

```

`SKILL.md` 结构：

| 章节 | 内容 |
|---|---|
| 〇、先选方法 | 按体量选法 + 抽样的三个合法场合 |
| 一、七步 | 划分母体 → 建索引 → 分层抽样 → 估计精度 → Neyman 分配 → 定点读 → 停止规则 |
| 二、六条不变量 | 先建模 / 分母闭合 / 随机+分层 / 报行号 / 先报价 / 落盘 |
| 三、覆盖率三种口径 | 分母必须写旁边 |
| 四、四条禁忌 | 不能替代精读、不能跳读有序材料、CI 只在随机时有效、捕再捕有前提 |
| 五、证伪自己 | 三次判反的实测 |
| 六、验收 | 6 条可勾选 |

---

## 适用范围

| 适合 | 不适合 |
|---|---|
| 几十万行对话 / 文档，要出结论又要能验算 | 一个文件精读（直接用 read） |
| 要回答「总体占几成」 | 要回答「这句话在哪」（用 grep） |
| 要证明「这块没价值」 | 材料是图片、需要 OCR（做不了就直说） |

## 环境要求

与平台无关。抽样公式与停止规则是通用的；
文中的行数、成本数据来自一次真实项目的实测，**换环境请按文中方法重新标定**。

## 怎么用

### 在 DSH 里

```
%USERPROFILE%\.dsh\skills\corpus-reading\SKILL.md
```

### 在 Claude Code 里

```
%USERPROFILE%\.claude\skills\corpus-reading\SKILL.md
```

### 手动使用

不需要自动加载的话，直接把 `SKILL.md` 内容贴给 AI，说「按这个流程读这批材料」也可以。
